# CFG register residency and shared selection: 2026-11-05

**Local dual-compiler execution passes; new-source timing and final acceptance
remain open.** Engine source: `2be7d9f17b54b7ed5582faabd741f0f5fa9c01c7`.
This corrects the [loop-residency experiment](performance-loop-value-coalescing-2026-11-05.md),
whose lexical-loop extension did not recover the hosted x86 regression.

An iterative, bounded Tarjan traversal now identifies actual CFG cycles.
The memory fixture places its return block before the loop: the backward
layout edge to that return is acyclic. Treating it as a loop extended unrelated
lifetimes across the whole hot body. The corrected pass excludes that edge
and includes the actual reset and accumulation cycles. An independent
reachability oracle checks all 512 directed three-node graphs; deep graphs
exercise the nonrecursive traversal. This remains slot residency, not general
SSA/value-version allocation.

Eviction now reuses the conservative allocator's existing access costs instead
of preferring cheap short-lived words over the loop-carried accumulator.
No second cost analysis is added. The affected x86 private-memory fixture has
six available cached integer registers, compared with eighteen on arm64;
the earlier arm64 diagnosis therefore missed the x86 register-pressure failure.
Canonical frame snapshots, typed edge moves, cold entries and poll contracts
remain required.

Ordinary functions and bounded native regions now share one ordered selector
pipeline, removing 57 net production lines in the consolidation commit.
Logical shifts, live integer literals and i31 selection are retained in regions.
Models compare every original PC and interrupted private backedge with the
independent precise native tier, including all live literal frame words.
Large literals that the target cannot encode keep their ordinary lowering.
This changes no CPU feature policy, toolchain pin, alignment or fuel semantics.
