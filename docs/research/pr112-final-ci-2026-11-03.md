## Separate current-source duration and boundary controls

The public-API 10000-call control verifies 180 observations, 36 alternate checks
and 36 summaries across five fresh process blocks. LLGo empty interpreter is
648.36→639.58 ns/call, native 842.31→840.25; native baseline A/A changes +1.65%.
LLGo 64-step native calls increase 1.16% while A/A changes -1.06%; retain it.
Wasmtime empty is 60.03 ns, Wasmer 138.37 and wazero compiler default/enabled
13.82/276.85. Policies differ; no empty/clock median is subtracted. Original
single-call outcomes are not replaced by batching.

The separate duration study verifies 265 observations, 53 alternate checks,
50 independent affine-oracle checks and 53 summaries over seven backend/cases.
Original 1m live-chain allocation exceeds the unchanged 64 MiB guest-heap quota;
its failure is retained. Before any warmed allocation observation, the count
is amended to 300k; seventy completed observations in the first two cases stay
byte-for-byte unchanged. The original plan conservatively stated 80 bytes/object;
actual packed payload is 12 bytes plus 64 accounting bytes, so 300k/old+new chains
account for 22.8/45.6 MB. No policy or quota changes.

Long native LLGo direct/indirect access is 1.286/4.560 ns versus Wasmtime
1.027/2.560. Long allocation is 62.03 ns/object versus 8.99, about 6.90x;
short allocation results did not establish that sustained behavior. Original
short adverse observations, new native wait-mismatch +0.73% and all A/A values
remain retained.

Five-second sampling of 512 checked public native calls per compiler points to
collection, compaction and batch commit. LLGo's main thread has 2335/3975 stacks
in the collector path; waiting marker threads are excluded from that one-profile
denominator. Sampling-perturbed timings are excluded from comparisons; no exact
cycle or compiler-defect attribution follows.

Controlled portfolio, public-boundary, ordinary-C, allocation/cancellation and
expanded WASI-world acceptance remain open. The next shared collector experiments
retain this merged implementation as their baseline.
